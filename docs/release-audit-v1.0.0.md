# Public-release audit: v1.0.0

Prepared 11 September 2026. This is a bounded prepublication review, not a
security certification or a claim that automated scanners detect all secrets.

## Scope

- All 20 reachable pre-release commits through `0ccbfca13f65c7e08a83f100052bdadc1d45dd69`,
  their blobs and commit metadata, plus the final release-documentation diff.
- All 25 existing GitHub Actions runs (every log archive was available).
- The prospective manuscript-free evidence asset.
- The repository had no issues/PRs, uploaded Actions artifacts, wiki, Pages,
  discussions, or previous GitHub releases at the time of the audit.

## Findings and disposition

Gitleaks 8.30.1 was downloaded from its official GitHub release; its archive
checksum was verified before local execution. Default rules were used, with
matched values redacted in scanner output.

- Current source: 104 generic-key detections, all reviewed. Of these, 56 are
  deterministic `cap-` markers generated by the synthetic authorization
  fixture, and 48 are repetitions of a synthetic lineage identifier.
- Git history: the same 104 fixture detections. Every capability match was
  verified against its profile's deterministic valid/invalid generator.
- GitHub logs: no secret detections.
- Evidence asset: 1,030 generic-key detections, all repetitions of the same
  synthetic lineage identifier in preserved responses, contracts, or analyses.
- An additional targeted privacy scan found no real installed-agent identity,
  private conversation, local user-home path, or private-project reference in
  the prospective content. Existing Git author/committer account attribution
  is intentionally retained; repository history is not anonymous.

No genuine credential was identified in this review. No secret was removed
from a frozen response to improve a score. Fixture detections were classified,
not silenced with a blanket scanner exclusion.

## Verification

- Main repository: 133 tests, passed; 2 environment-dependent skips.
- Frozen benchmark regeneration: 83 files verified unchanged.
- Historical evidence: integrity/numerical verifier passed; 117 snapshot
  tests passed, with 2 documented source-prototype regeneration skips.
- Evidence packaging preserves included original response and judgment bytes,
  adds an explicit export manifest, and excludes manuscript/supplement files.
- No new target or evaluator inference was run for this release.

The release asset carries its own SHA-256 manifest. It preserves earlier
sanitization and records that provenance; it is not described as untouched
runtime output. See [reproducing the paper](reproducing-paper.md).
